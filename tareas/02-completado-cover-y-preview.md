# Tarea 02 — Cover y vista previa ligera

Estado: completado.

## Alcance
Prueba corta de Cover, variante sin FSQ para canciones largas, generación MP3 128 kbps para escuchar y WAV sin pérdida separado para descargar.

## Archivos
